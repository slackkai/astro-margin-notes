# Margin Notes 1.0.0

首次发布：手绘笔记本风格的 Astro 主题，包含学术、洞见、日常、资料库与项目五个内容板块。

- 修复未完成的配置迁移、GitHub Pages 子路径、标签路由、搜索与页面交互问题。
- 支持 Markdown / MDX、KaTeX、页边批注、四套配色、目录、阅读进度、RSS 与归档。
- 集成 Sveltia 可视化内容管理：文章、图片、站点信息与 Now 卡片保存到 GitHub 后自动部署。
- 提供模板仓库、MIT 许可、安装指南、内容管理指南和检查报告。

验证：Astro 检查零错误；路径与 CMS 回归测试通过；根路径和仓库子路径下的 52 个 HTML 页面、1,870+ 条站内引用通过检查；草稿/禁用板块的真实生产构建测试通过；浏览器验证搜索、MDX 公式、资料库筛选、窄屏菜单与 CMS 虚拟仓库保存。
