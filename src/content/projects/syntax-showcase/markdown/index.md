## 代码

```python
def ik(x, y, l1=1.0, l2=0.8):
    """两连杆逆运动学：给末端坐标，返回两个关节角。"""
    import math
    c2 = (x * x + y * y - l1 * l1 - l2 * l2) / (2 * l1 * l2)
    t2 = math.acos(max(-1.0, min(1.0, c2)))
    t1 = math.atan2(y, x) - math.atan2(l2 * math.sin(t2), l1 + l2 * math.cos(t2))
    return t1, t2
```

右上角的胶带标签写着语言名。行内代码 `like this` 还是原来的样子。

## 公式与脚注

行内公式 $\tau = J^\top F$，独立公式：

$$
\dot{q} = J^{+}(q)\,\dot{x}
$$

脚注会进页边[^j]，和行内批注共用编号。

[^j]: $J^{+}$ 是雅可比的伪逆；奇异位形附近要加阻尼。
